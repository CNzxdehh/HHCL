## v1.1.1 改了什么

**网盘分发的文件已刷新为最新构建**（v1.1.0 发布后重新打包，修了输入框显示问题）。

程序功能与 v1.1.0 相同，主要是界面的几处修正：

· 输入框里的文字改成**贴左显示**（之前是居中，看着像前面空了一堆）
· 输入框不再被拉伸到撑满整行（之前能到 823px 宽，右边全是空白）
· 密码框不再自动填随机数，改为占位提示「请填入密码」
· 去掉客机区两个没用的「粘贴」按钮
· 去掉开房间前那段没意义的提示文字
· 状态栏右下角的版本号改成跟 `AppInfo` 走，升级只改一处

**v1.1.0 的主功能：联机房间访问密码**（详见 v1.1.0 的说明）

· 主机侧开一个代理端口（默认 45679），朋友先连代理，**密码对了才转发给游戏**
· 密码**在主机这边校验**，填错连不上
· 客机侧起本地代理，游戏照常用「直连地址」流程，代理完成密码握手后转发
· 密码用固定时间比较，防时序侧信道
· **不填密码时行为和以前完全一样**，老用法不受影响

> ⚠️ 同一个局域网里，别人若直接填**游戏端口（房间码）**仍可能绕过密码
> （集成服务器自己监听所有网卡，拦不住）。跨网联机请只把**代理端口**映射出去。

## 运行要求

· Windows 10 1607 及以上（64 位）
· 玩正版需要**你自己的**微软账号（免费账号即可），启动器只做官方 OAuth 登录
· 缺 Java 时启动器会提示一键下载 Java
· 首次启动如提示防火墙，选「允许专用网络」（局域网联机需要）

## 功能

· 多版本管理：原版 + Fabric / Forge / NeoForge / Quilt
· 联网搜索安装模组、资源包、光影、整合包（中文关键词会自动补搜英文同义词）
· 版本详情页按游戏版本分组，每组可折叠展开
· 局域网联机：房间码 + 直连地址 + UDP 广播自动发现附近房间，支持访问密码
· 基岩版：可下载安装，支持多存档配置隔离
· 深色 / 浅色双主题，界面中文，游戏语言自动切简体中文
