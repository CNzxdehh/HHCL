## v1.1.0 更新了什么

**新增：联机房间访问密码**

之前联机是「开放到局域网」，**Minecraft 的集成服务器本身没有密码**——只要知道地址谁都能进。
v1.1 在主机侧加了一层带认证的转发：

· 主机自动开一个代理端口（默认 45679），朋友先连代理，**密码对了才转发给游戏**
· 密码**在主机这边校验**，不是客机自觉填一下那种形式，填错连不上
· 客机侧起一个本地代理，游戏照常用「直连地址」那套流程，代理完成密码握手后再转发
· 密码用固定时间比较，防时序侧信道
· **不填密码时行为和以前完全一样**（直连游戏端口），老用法不受影响

用法：开房间页勾「访问密码」→ 填密码或点「随机」→ 房间信息里会显示联机地址和密码，
一键复制发给朋友；朋友在「加入房间」页填地址 + 密码就能进。

> ⚠️ 同一个局域网里，别人若直接填**游戏端口（房间码）**仍可能绕过密码（集成服务器自己监听所有网卡，拦不住）。
> 跨网联机请只把**代理端口**映射出去。

## 运行要求

· Windows 10 1607 及以上（64 位）
· 玩正版需要**你自己的**微软账号（免费账号即可），启动器只做官方 OAuth 登录
· 缺 Java 时启动器会提示一键下载 Java
· 首次启动如提示防火墙，选「允许专用网络」（局域网联机需要）

## 功能

· 多版本管理：原版 + Fabric / Forge / NeoForge / Quilt
· 联网搜索安装模组、资源包、光影、整合包（中文关键词会自动补搜英文同义词，"小地图"也能搜到 Xaero 小地图）
· 版本详情页按游戏版本分组，每组可折叠展开
· 局域网联机：房间码 + 直连地址 + UDP 广播自动发现附近房间，**v1.1 支持访问密码**
· 基岩版：可下载安装，支持多存档配置隔离
· 深色 / 浅色双主题，界面中文，游戏语言自动切简体中文
