   - 空仓库不能直接 `POST /git/trees`（409 "Git Repository is empty"）→
     先 `PUT /contents/README.md` 建首个 commit（自动建分支），再 `GET /git/refs/heads/master`

| 路径 | 结果 |
|---|---|

| 本地 **https** 服务 + `--ignore-https-errors` | agent-browser **daemon 已在运行时会忽略该参数**，

| 浏览器 fetch `uploads.github.com` | **CORS 拦**：OPTIONS 预检返回 400（4 种 header 组合全试过都挂） |
| 浏览器 fetch `api.github.com` 带 Bearer | ✅ **完全可用**（建仓库/提交代码/blob 都成功） |
| `GET/DELETE /authorizations` | ❌ **只认 Basic auth 且不支持跨域**（Bearer → Failed to fetch）→ 撤 token 只能用户手动 |
| 走 gh-proxy 加速 | ❌ 它**剥离 Authorization**（URL 内嵌凭据也一样），并把请求换成自己共享池的 token

## 09:20 联机优化：房间自动发现 + 复制话术
用户："联机能不能优化一下？"

**新增：局域网房间自动发现**（不用手抄 IP）
- 新增 `Core/LanDiscovery.cs`：主机检测到游戏端口后 `StartResponder(port)`，
  在本机 **UDP 45678** 上应答；客机 `ScanAsync()` 广播 "HELLO"
  （发到 255.255.255.255 + 各网段广播地址，由本机 IPv4 推算），主机回 "ROOM|ip|游戏端口"。
- UI：加入房间面板加「附近的房间」列表 + 「搜索房间」按钮，列表每项有地址/房间码和「加入」按钮
  （点了自动填地址并直连）。扫不到时提示"可能没开局域网或防火墙拦了 UDP"。
- 主机侧加「复制这段话」按钮（一键复制给朋友的说明）。
- 联机页「启动游戏」按钮从页面最右挪到版本下拉右边（列定义 Auto/Auto/Auto/*）。

**实测**：`--lan scan`（自己当主机再自己扫）→ 扫到 1 个房间 192.168.31.183:51234 ✓

**踩坑**：`UdpClient.ReceiveAsync(ct)` 不带超时会**永久挂住**（第一次自检进程被 timeout 杀掉、
lan.txt 没写出来才发现）。修法：每次接收用
`using var one = CancellationTokenSource.CreateLinkedTokenSource(ct); one.CancelAfter(300);`
